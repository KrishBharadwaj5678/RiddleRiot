<h1 align="center"><img src="https://github.com/KrishBharadwaj5678/RiddleRiot/raw/main/assets/icons/icon.png" width="35"/>  Riddle Riot</h1>

<p align="center">
  RiddleRiot is a Python-based web application that offers a variety of random challenges designed to test logic and problem-solving skills.
</p>

## <img src="https://github.com/KrishBharadwaj5678/RiddleRiot/raw/main/assets/readme/features.gif" width="35"/> Features

| Feature                  | Description                               |
| ------------------------ | ----------------------------------------- |
| 🎲 **Riddle Generator**  | Generates a random riddle                 |
| 🔗 **API Integration**   | Fetches riddles from API Ninjas            |
| 🧩 **Title & Question**  | Displays the riddle title and question    |
| 💡 **Reveal Answer**     | Click to reveal the riddle answer         |
| 📲 **Responsive UI**     | Works smoothly on desktop and mobile devices |

## <img src="https://github.com/KrishBharadwaj5678/RiddleRiot/raw/main/assets/readme/gettingStarted.gif" width="35"/> Getting Started

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/KrishBharadwaj5678/RiddleRiot.git
````

### 2️⃣ Navigate to Folder

```bash
cd RiddleRiot
```

### 3️⃣ Install Dependencies

```bash
pip install -r requirements.txt
```

### 4️⃣ Run the Application

```bash
streamlit run app.py
```
