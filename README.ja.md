<h1 align="center"><img src="https://github.com/KrishBharadwaj5678/RiddleRiot/raw/main/assets/icons/icon.png" width="35"/> Riddle Riot</h1>

<p align="center">
  RiddleRiotは、論理的思考力や問題解決能力を試すさまざまなランダム問題を提供する、PythonベースのWebアプリケーションです
</p>

## <img src="https://github.com/KrishBharadwaj5678/RiddleRiot/raw/main/assets/readme/features.gif" width="35"/> 機能

| 機能 | 説明 |
| ---- | ---- |
| 🎲 **なぞなぞジェネレーター** | ランダムななぞなぞを生成します |
| 🔗 **API連携** | API Ninjasからなぞなぞを取得します |
| 🧩 **タイトルと問題** | なぞなぞのタイトルと問題文を表示します |
| 💡 **答えを表示** | クリックしてなぞなぞの答えを表示できます |
| 📲 **レスポンシブUI** | デスクトップとモバイルデバイスの両方で快適に利用できます |

## <img src="https://github.com/KrishBharadwaj5678/RiddleRiot/raw/main/assets/readme/gettingStarted.gif" width="35"/> はじめに

### 1️⃣ リポジトリをクローン

```bash
git clone https://github.com/KrishBharadwaj5678/RiddleRiot.git
```

### 2️⃣ プロジェクトフォルダへ移動

```bash
cd RiddleRiot
```

### 3️⃣ 依存関係をインストール

```bash
pip install -r requirements.txt
```

### 4️⃣ アプリケーションを起動

```bash
streamlit run app.py
```
