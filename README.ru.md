<h1 align="center"><img src="https://github.com/KrishBharadwaj5678/RiddleRiot/raw/main/assets/icons/icon.png" width="35"/> Riddle Riot</h1>

<p align="center">
  RiddleRiot это веб-приложение на Python, предлагающее разнообразные случайные задания, которые помогают проверить логическое мышление и навыки решения задач
</p>

## <img src="https://github.com/KrishBharadwaj5678/RiddleRiot/raw/main/assets/readme/features.gif" width="35"/> Возможности

| Возможность | Описание |
| ----------- | -------- |
| 🎲 **Генератор загадок** | Генерирует случайную загадку |
| 🔗 **Интеграция с API** | Получает загадки через API Ninjas |
| 🧩 **Название и вопрос** | Отображает название и текст загадки |
| 💡 **Показ ответа** | Нажмите, чтобы увидеть ответ на загадку |
| 📲 **Адаптивный интерфейс** | Плавно работает на компьютерах и мобильных устройствах |

## <img src="https://github.com/KrishBharadwaj5678/RiddleRiot/raw/main/assets/readme/gettingStarted.gif" width="35"/> Начало работы

### 1️⃣ Клонирование репозитория

```bash
git clone https://github.com/KrishBharadwaj5678/RiddleRiot.git
```

### 2️⃣ Переход в папку проекта

```bash
cd RiddleRiot
```

### 3️⃣ Установка зависимостей

```bash
pip install -r requirements.txt
```

### 4️⃣ Запуск приложения

```bash
streamlit run app.py
```
