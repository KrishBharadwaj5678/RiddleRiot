<h1 align="center"><img src="https://github.com/KrishBharadwaj5678/RiddleRiot/raw/main/assets/icons/icon.png" width="35"/> Riddle Riot</h1>

<p align="center">
  RiddleRiot é uma aplicação web baseada em Python que oferece uma variedade de desafios aleatórios projetados para testar o raciocínio lógico e as habilidades de resolução de problemas
</p>

![RiddleRiotDemo](https://github.com/KrishBharadwaj5678/RiddleRiot/raw/main/assets/demos/RiddleRiot.png)

<img src="https://github.com/KrishBharadwaj5678/RiddleRiot/raw/main/assets/readme/divider.gif" width="100%"/>

## <img src="https://github.com/KrishBharadwaj5678/RiddleRiot/raw/main/assets/readme/features.gif" width="35"/> Recursos

| Recurso | Descrição |
| ------- | --------- |
| 🎲 **Gerador de Charadas** | Gera uma charada aleatória |
| 🔗 **Integração com API** | Busca charadas através da API Ninjas |
| 🧩 **Título e Pergunta** | Exibe o título e a pergunta da charada |
| 💡 **Revelar Resposta** | Clique para revelar a resposta da charada |
| 📲 **Interface Responsiva** | Funciona perfeitamente em computadores e dispositivos móveis |

## <img src="https://github.com/KrishBharadwaj5678/RiddleRiot/raw/main/assets/readme/gettingStarted.gif" width="35"/> Primeiros Passos

### 1️⃣ Clone o repositório

```bash
git clone https://github.com/KrishBharadwaj5678/RiddleRiot.git
```

### 2️⃣ Acesse a pasta do projeto

```bash
cd RiddleRiot
```

### 3️⃣ Instale as dependências

```bash
pip install -r requirements.txt
```

### 4️⃣ Execute a aplicação

```bash
streamlit run app.py
```
